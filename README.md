# 牛股策略计算器（娜美老师修改版）



## 一、参考Xhox佬，增加了自动找高低点的功能

填一段行情的最高点和最低点（不填也行，工具会自动找），算出三条回撤线：

| 位置 | 怎么理解 |
|---|---|
| 0.382 | 浅回踩，强势股一般跌到这就有人接 |
| 0.618 | 多空分界，跌破这里说明走弱了 |
| 0.786 | 跌到这套牢盘太重，大概率还要杀，别看了 |

**自动找高低点的规则（按波段结构找，不被日历窗口截断）：**

- 在最近 180 个交易日的K线上，用 MACD 金叉/死叉把行情切成一段一段的波段
- **底**：金叉所终结的那段下跌里的最低点（也就是这波行情的真实起涨点）
- **顶**：死叉所终结的那段上涨里的最高点
- 最后一次交叉之后还在走的行情，新高新低会实时跟上（包括死叉后顶背离创的新高）
- 盘中没走完的K线不拿来确认金叉死叉（防止信号盘中闪烁），但盘中摸到的价格算数
- 实在一个交叉都没有，就退回近 30 日最高最低价兜底
- 你手动填过的值不会被自动覆盖

**重算按钮**：手填错了、或者股票除权了，点一下「重算」就按上面的规则重新算一遍（这个会覆盖手填值）。

**除权提醒**：分红送转之后，以前存的顶底全是旧价格基准，已经不准了。工具会自动检测，发现除权就在股票名旁边挂一个橙色的「除权?」标签，看到了就去点重算。

## 三、增加了关于搓揉线的功能

增加了K线图，点击对应的股票旁边的小图标可以弹出来，K线图上画了 MA5 / MA15 / MA20 三条均线，还添加了娜美佬的线。

用昨天的K线加今天的实时K线，看是不是搓揉线（就是长上影、长下影来回甩的那种，影线得有实体的 1.5 倍、占全天振幅四成以上才算数）。配合趋势和今天收阴收阳，一共八种情况：

| 趋势 | 今天 | 影线顺序 | 说明 |
|---|---|---|---|
| 下跌 | 阴线 | 先下影后上影 | 中继下跌，还要跌 |
| 下跌 | 阳线 | 先下影后上影 | 支撑位震荡，等选方向 |
| 下跌 | 阳线 | 先上影后下影 | 有资金在抢反弹 |
| 下跌 | 阴线 | 先上影后下影 | 短期止跌了 |
| 上涨 | 阴线 | 先下影后上影 | 开始有分歧 |
| 上涨 | 阳线 | 先下影后上影 | 有分歧但还强，继续看新高 |
| 上涨 | 阳线 | 先上影后下影 | 下面接得住，但别追高 |
| 上涨 | 阴线 | 先上影后下影 | 接不住了，小心短期见顶 |

趋势怎么判：看现价和 MA20 的位置、MA5 和 MA20 的位置、MA20 是往上还是往下，三个里面两个同向就算趋势成立。回踩跌破 MA5 不影响判断；三个打架就显示"趋势不明"。

## 四、日内压力和支撑

拿分时均价上下浮 1.15% 左右，算出当天的压力线和支撑线。

## 五、股票分组

选的股太多了看不过来，加了分组功能：

- 表格上面一排分组标签（全部 / 各分组 / 未分组），点哪个看哪个
- 「管理分组」里可以新增、重命名、删除分组（删分组不删股票，股票回到未分组）
- 每行有个分组下拉，直接改这只股票归哪组
- 在某个分组标签下添加的新股票，自动进这个分组
- 导出导入 CSV 时分组也会跟着走

## 六、大盘模块（黄白线）

页面顶上常驻一条大盘行情：上证指数 / 深证成指 / 创业板指，红涨绿跌，盘中自动刷新。

点任何一个指数弹出大图，有两个视图：

- **分时（黄白线）**：白线是所选指数当天的走势，黄线是中证1000（小盘股代表），都画在涨跌幅坐标上。黄线在白线上面 = 小票比权重强（普涨、题材活跃）；白线在上面 = 权重在拉指数、中小票跟不上（小心虚假繁荣）。下面带成交量柱。
- **日K线**：指数蜡烛图 + MA5 / MA15 / MA20。
