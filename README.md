# 牛股策略计算器（娜美老师修改版）



## 一、参考Xhox佬，增加了自动找高低点的功能

填一段行情的最高点和最低点（不填也行，工具会自动找），算出三条回撤线：

| 位置 | 怎么理解 |
|---|---|
| 0.382 | 浅回踩，强势股一般跌到这就有人接 |
| 0.618 | 多空分界，跌破这里说明走弱了 |
| 0.786 | 跌到这套牢盘太重，大概率还要杀，别看了 |

**增加了自动找高低点的规则：最近 30 个交易日里，MACD 金叉前一天的低点当底，死叉前一天的高点当顶；找不到就直接用 30 日内最高最低价。你手动填过的不会被覆盖。**

## 三、增加了关于搓揉线的功能

增加了K线图，点击对应的股票旁边的小图标可以弹出来，包括了30日内的k线图，还添加了娜美佬的线。

用昨天的K线加今天的实时K线，看是不是搓揉线（就是长上影、长下影来回甩的那种，影线得有实体的 1.5 倍、占全天振幅四成以上才算数）。配合趋势和今天收阴收阳，一共八种情况：

| 趋势 | 今天 | 影线顺序 | 说明 |
|---|---|---|---|
| 下跌 | 阴线 | 先下影后上影 | 中继下跌，还要跌 |
| 下跌 | 阳线 | 先下影后上影 | 支撑位震荡，等选方向 |
| 下跌 | 阳线 | 先上影后下影 | 有资金在抢反弹 |
| 下跌 | 阴线 | 先上影后下影 | 短期止跌了 |
| 上涨 | 阴线 | 先下影后上影 | 开始有分歧 |
| 上涨 | 阳线 | 先下影后上影 | 有分歧但还强，继续看新高 |
| 上涨 | 阳线 | 先上影后下影 | 下面接得住，但别追高 |
| 上涨 | 阴线 | 先上影后下影 | 接不住了，小心短期见顶 |

趋势怎么判：看现价和 MA20 的位置、MA5 和 MA20 的位置、MA20 是往上还是往下，三个里面两个同向就算趋势成立。回踩跌破 MA5 不影响判断；三个打架就显示"趋势不明"。

## 四、日内压力和支撑

拿分时均价上下浮 1.15% 左右，算出当天的压力线和支撑线。
